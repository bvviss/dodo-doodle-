# Doodle Chain 🎨

A drawing-and-guessing party game for 3–10 friends, played in the browser.
No accounts, no install.

> This README is being written as the game is built. The full step-by-step
> guide (including putting the game online) arrives in the final milestone.

## Run it on your computer

1. Install **Node.js** (the "LTS" version) from https://nodejs.org
2. Open a terminal in this folder and run:

   ```bash
   npm install
   ```

   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 in your browser.

## Run the tests

```bash
npm test
```
